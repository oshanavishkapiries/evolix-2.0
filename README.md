# Evolix 2.0

Evolix is a streaming application with a Next.js web app, an independent Evo Engine for media processing, and supporting media tools.

All project guides and references are organized in [the documentation index](docs/index.md).

- [Local development](docs/development/local-development.md)
- [Application configuration](docs/configuration/application-configuration.md)
- [Evo Engine deployment](docs/evo-engine/deployment.md)
- [Backend API](docs/api/backend-api.md)
- [Media tools](docs/tools/index.md)

Copy the root and engine `.env.example` files to their respective `.env` files and configure credentials as described in the guides. Keep credentials out of version control.
